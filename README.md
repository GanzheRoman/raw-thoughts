# Персонал — учёт объектов, людей и бригад

Веб-система для компании, поставляющей персонал на объекты (форумы, стройки и т.п.).
Без внешних зависимостей: только Node.js ≥ 18.

## Запуск

```bash
npm start            # http://localhost:3000
PORT=8080 npm start  # другой порт
```

Данные хранятся в `data/db.json` (создаётся при первом запуске с демо-данными; `DATA_DIR` меняет папку).
Для хостинга на сервере достаточно запустить `node server.js` (systemd/pm2) и при желании поставить nginx с HTTPS.

## Возможности

- **Дашборд** — выручка, оплата рабочим, маржа, часы, активные рабочие, объекты, график по дням, разрезы по объектам и бригадирам.
- **Объекты** — статусы (запланирован / текущий / закрыт); канбан с drag&drop и карта (Leaflet/OSM) — два представления одних данных. На карте: добавление кликом, перетаскивание маркеров, смена статуса, удаление.
- **Табель** — по дням: кто, на каком объекте, часы, ставка рабочего и ставка для заказчика; копирование предыдущего дня.
- **Рабочие** — вся база людей, «чей человек» (бригадир), статус (активен / неактивен / ненадёжный), поиск и фильтры.
- **Бригады** — бригадиры и их люди, смена статусов на месте.
- **Задачи** — канбан с ответственными из бригадиров и администраторов.
- **Администраторы** — список админов платформы (для назначения задач).

Авторизации пока нет. Тайлы карты грузятся с openstreetmap.org (нужен интернет у пользователя), остальное работает офлайн.
